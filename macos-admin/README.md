# ByteStore Admin 0.2 для macOS

Откройте `dist/ByteStore Admin.app`. Приложение работает с общей PostgreSQL-базой магазина в Supabase. Нужен интернет. Каталог, цены, остатки и заказы общие с сайтом https://stereofox08.github.io/Diplom/.

Входите по e-mail и паролю администратора ByteStore. Прежние `Admin / 1234` относятся только к старой локальной демонстрации и больше не используются. Данные доступа сохранены отдельно, вне репозитория.

Доступны 10 разделов существующей админки, нативное меню macOS, выбор файлов, CSV/JSON-экспорт. Интерфейс поставляется внутри приложения в WKWebView; для запуска браузер и локальный сервер не нужны. Кнопка обновления и Cmd+R получают актуальные данные с сервера. Заказы сохраняются для истории; вместо удаления используйте отмену. Вместо удаления клиентов используйте блокировку.

Сборка: `python3 build.py`. Требуются Xcode, Python 3, Apple Silicon и macOS 13+. Скрипт берёт сайт из соседней папки `site`, либо из указанного аргументом пути. В репозитории исходники приложения лежат в `macos-admin/`, сборка берёт сайт из корня репозитория.

JSON-экспорт — снимок данных, а не полная резервная копия PostgreSQL и Auth. Интернет-эквайринг, отправка писем через собственный SMTP и прокси внешнего ИИ настраиваются отдельно.

Проверка: `ByteStoreAdmin --smoke-test`. Секретный файл учётных данных передаётся через `BYTESTORE_SMOKE_CREDENTIALS`. Проверяются настоящий вход, общий каталог, 10 разделов, перезагрузка с сохранением сессии и выход. Результат сохраняется в `/tmp/bytestore-admin-smoke.txt`; используется отдельное временное хранилище WebKit.

Общий стиль и шрифты берутся из `DESIGN.md` и `design/tokens.json` родительского репозитория. Для передачи приложения используйте `dist/ByteStore-Admin-macOS.zip`: архив создаётся из подписанной сборки до копирования в облачную папку.

### Тёмная тема

Начиная с 0.2.1, кнопка «Тема» доступна на экране входа и справа в верхней панели админки. Также есть меню «Вид → Сменить тему» (⌘T). Выбор сохраняется; оформление окна macOS следует теме содержимого.
