# ByteStore Admin для Android

Отдельное нативное приложение сотрудников: `kz.bytestore.admin`. Устанавливается рядом с магазином `kz.bytestore.shop`; не использует его вход, корзину, хранилище, настройки или компоненты Android. Общая только серверная база ByteStore. WebView отсутствует.

## Возможности

Обзор магазина, товары (создание, редактирование характеристик, себестоимость, публикация, остатки с проверкой версии, копирование и удаление), фото с телефона или по HTTPS, категории, заказы и их история/статусы/комментарии, клиенты и блокировка, модерация и ответы на отзывы, промокоды, настройки доставки и ИИ, журнал действий. Светлая, тёмная и системная темы.

Сервер остаётся владельцем разрешений и переходов статуса. Полученный или отменённый заказ нельзя вернуть в обработку. Отмена возвращает остатки на сервере. Удаление учётных записей Auth из приложения не предлагается; используется блокировка. Изменения общие для магазина и настольной админки.

## Безопасность

В сборке только публичный publishable key. После входа приложение проверяет `store_snapshot.isAdmin`; все изменения повторно проверяет существующий серверный `store_command`. Сессия зашифрована AES-GCM ключом Android Keystore в собственном пространстве приложения. Клиенты, заказы, себестоимость и настройки ИИ не кэшируются на диске. Снимки экрана и системный предпросмотр защищены FLAG_SECURE. Выход отзывает только текущую сессию, не затрагивая магазин/другие устройства.

Формы сохраняются в памяти при повороте экрана, сетевые ошибки не очищают ввод, конфликт версии товара требует обновления. После неопределённого сетевого результата изменения повторная отправка блокируется до обновления данных. Все удаления и блокировки требуют подтверждения. Поиск локальный по разрешённому сервером снимку, списки показывают по 20 записей. Это намеренное использование существующего API снимка, без новой серверной пагинации.

## Сборка

Android SDK 35 и JDK 17:

```sh
ANDROID_HOME="$HOME/Library/Android/sdk" JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home ./gradlew --project-cache-dir /private/tmp/bytestore-admin-gradle-cache -PbyteStoreBuildDir=/private/tmp/bytestore-admin-build assembleDebug assembleDebugAndroidTest lintDebug
```

Сборка debug подписана локальным ключом для диплома. Для Google Play нужен постоянный release-ключ. `design/generate.py` формирует общие цвета, шрифты и копию канонического Android-компонента Ui в отдельный пакет.

`AdminChecks` проверяет реальный вход/снимок и отказ анонимному пользователю. CRUD/конфликты/сбой связи проверяются через подставной транспорт и не изменяют реальные товары, клиентов или заказы. Для живой проверки временный файл `files/staff-smoke.json` передаётся через `run-as` и удаляется в finally; он никогда не включается в APK или репозиторий. Снимки тестового интерфейса создаются в собственном процессе исключительно на фикстурах.
