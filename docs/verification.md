# Проверка версии с общей базой — 22 октября 2026

- GitHub Pages публикует магазин с подключением к Supabase PostgreSQL: 60 товаров, 11 категорий.
- Проверены главная, каталог, конфигуратор, вход, экран регистрации и форма заказа. Ошибок JavaScript в этих сценариях нет.
- Проверены настоящая форма изменения цены в админке, доступность новой цены другому клиенту, запрет устаревшего сохранения и HTTP 409.
- Проверены серверный заказ, изоляция заказов покупателей, запрет покупателю менять товары или подтверждать неполученную доставку.
- Одновременная покупка последнего товара создаёт ровно один успешный заказ; повтор идентичного запроса не создаёт дубликат.
- Проверены отмена с однократным возвратом остатков и модерация отзывов.
- Приложение macOS прошло вход через Supabase, загрузку общей базы, открытие 10 разделов, перезагрузку с восстановлением сессии и выход.
- `admin.html` и SQL-файлы возвращают HTTP 404 на GitHub Pages. Временные аккаунты покупателей и тестовые заказы удалены.
- Проверка Supabase не выявила предупреждений по RLS, политикам или путям поиска функций. Осталось предупреждение о [проверке скомпрометированных паролей](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection): она доступна начиная с Pro. Платный тариф не включался.

## Оставшиеся подключения

Для публичной регистрации и восстановления пароля нужен собственный SMTP-отправитель в Supabase Auth. Сейчас подтверждение e-mail включено; тестовый отправитель Supabase ограничивает адресатов и частоту отправки. Минимум пароля в интерфейсе — 8 символов.

Рабочий способ оплаты — при получении. Реальные банковские платежи, прокси внешнего ИИ и общая аналитика посещений ещё не подключены. Корзина и избранное сохраняются на устройстве.
