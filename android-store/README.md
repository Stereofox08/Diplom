# ByteStore — нативное приложение для Android

Приложение магазина для покупателей, Android 8.0 и новее. Пакет `kz.bytestore.shop`. Все экраны реализованы средствами Android на Java; HTML, JavaScript и WebView в приложение не входят. Интерфейс построен как мобильный магазин: поиск сверху, категории, быстрые действия, рекомендации, список категорий каталога, сгруппированное меню профиля и отдельное пустое состояние корзины. Рекламная главная сайта не переносится. Сохранён логотип ByteStore; оформление согласовано с сайтом и админками через `../design/tokens.json` и сгенерированный `BrandTokens.java`. Manrope и Inter встроены в APK; лицензии находятся в `app/src/main/assets/fonts`.

## Возможности

Главная, каталог с поиском/категориями/сортировкой, карточки и характеристики товаров, избранное, сравнение до четырёх товаров, корзина, промокоды, ручной конфигуратор из 12 слотов с проверкой совместимости, сохранением черновика и передачей спецификации, автоматический подбор ПК под бюджет с выбором задачи, разрешения, платформы и охлаждения, вход/регистрация/восстановление доступа, профиль, история заказов и подтверждение получения. Четыре способа учебной оплаты используют существующий серверный checkout. Данные карты проверяются только на устройстве и не попадают в API или хранилище.

Подтверждение регистрации и восстановление пароля открываются по существующим ссылкам из письма в браузере. После подтверждения или смены пароля пользователь возвращается в приложение и входит с e-mail и паролем. Источник товаров и заказов — общая база Supabase сайта и админок.

## Каталог и наличие

- Каталог показывается сразу из SQLite; в первом APK также есть публичный стартовый снимок каталога.
- При открытии/возвращении в приложение и каждые 45 секунд в активном приложении запрашиваются актуальные цены и остатки. Карточки каталога обновляются на месте с сохранением поиска и позиции списка.
- До успешной серверной проверки добавление товаров в корзину выключено. При ошибке сети каталог можно просматривать, но покупать по старым остаткам нельзя. На экране виден статус проверки.
- Сервер повторно проверяет существование товаров, остатки, цены и итоговую сумму при checkout. Идемпотентный идентификатор защищает повторную отправку заказа. Изменение стоимости требует повторного подтверждения суммы.
- Корзина и избранное сохраняются на устройстве отдельно для каждого аккаунта; гостевая корзина переносится при входе. Локальный кэш содержит только каталог, категории, промокоды и публичные настройки доставки, без аккаунтов, заказов или закупочных цен.

## Безопасность

В клиент включён публичный publishable key; секретного ключа и аккаунта администратора нет. Авторизация и права проверяются существующей базой/RLS. Сессия шифруется AES-GCM с ключом Android Keystore; пароль не сохраняется. Сетевые запросы используют HTTPS без обхода проверки сертификата; резервное копирование и перенос данных приложения запрещены. Код админки не включается в APK.

## Сборка

Нужны Java 17 и Android SDK 35. Укажите `sdk.dir` в `local.properties`. Версии Gradle Wrapper 8.9, Android Gradle Plugin 8.7.2 и ZXing 3.5.3 закреплены; контрольная сумма Gradle проверяется.

```sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
./gradlew assembleDebug lintDebug
```

Обычный результат — `app/build/outputs/apk/debug/app-debug.apk`. В папках, синхронизируемых облачным диском, можно вынести промежуточные файлы:

```sh
./gradlew --project-cache-dir /private/tmp/bytestore-native-gradle-cache \
  -PbyteStoreBuildDir=/private/tmp/bytestore-native-build \
  assembleDebug assembleDebugAndroidTest lintDebug
```

Сборка `debug` подписана локальным отладочным ключом и предназначена для установки и проверки диплома. Для Google Play нужна release-сборка с постоянным ключом подписи.

## Проверка на телефоне

При нескольких устройствах сначала задайте `ANDROID_SERIAL`, чтобы выбрать именно телефон.

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w kz.bytestore.shop.test/kz.bytestore.shop.NativeChecks
python3 tests/design-ui.py
python3 tests/device-ui.py
```

`NativeChecks` проверяет нативный HTTPS-клиент, кэш, шифрование сессии, корзину, промокоды, идемпотентность, проверку карты, совместимость сборки и блокировку кнопок до проверки наличия. Локальные проверки используют отдельное защищённое хранилище теста. `design-ui.py` проверяет структуру новых экранов и поиск без изменения корзины. `device-ui.py` проходит нативные экраны и меняет только гостевую корзину/избранное нового приложения; не запускайте его поверх личной корзины. Заказы и аккаунты проверки не создают.

Для Wi-Fi-сопряжения откройте на телефоне «Беспроводная отладка → Сопряжение с помощью кода»: адрес этого окна используется в `adb pair`. Основной адрес экрана отладки используется в `adb connect`; порт подключения отличается от порта сопряжения. Текущий адрес показывает `adb mdns services`, состояние — `adb devices -l`.

Оформление Violet Studio общее с сайтом и админками: светлая основа, графитовый текст, фиолетовые акценты, шрифты Inter/Manrope. Тёмная тема сайта сохранена. `configurator-ui.py` проверяет ручную сборку без изменений черновика и корзины; 2061 сочетание из веб-ядра проверяется NativeChecks.
