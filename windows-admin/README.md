# ByteStore Admin для Windows

Отдельное приложение для Windows 10/11, 64 бит. Интерфейс встроен в приложение; товары, заказы, отзывы и пользователи используют ту же базу Supabase, что сайт и macOS-админка. Нужен интернет.

## Запуск

Распакуйте весь ZIP в отдельную папку и откройте `ByteStore Admin.exe`. Остальные файлы рядом с EXE нужны для работы. Вход — существующий аккаунт администратора. Node.js, браузер и локальный веб-сервер устанавливать не нужно. Пакет не подписан сертификатом Microsoft.

Меню «Файл»: экспорт данных, открытие магазина, обновление и выход. JSON-экспорт — снимок доступных администратору данных, не полная резервная копия PostgreSQL/Auth. Корзина магазина и платёжные окна в приложение не входят.

## Сборка

Нужны Node.js 24 и pnpm 11.25.0. Зависимости закреплены в pnpm-lock.yaml; версия Electron — 45.0.0. На macOS для оформления Windows EXE сборщику может понадобиться Wine/CrossOver.

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm build
```

`build.mjs` берёт актуальные ресурсы из родительского репозитория. Можно передать путь к магазину: `node build.mjs /path/to/site`. Результат — `dist/ByteStore Admin-win32-x64/`.

Изоляция контекста и песочница включены, Node.js недоступен интерфейсу. Встроенный интерфейс не открывает удалённые страницы внутри окна. Ключ Supabase — публичный publishable key, права проверяются в базе. Пароли администратора в дистрибутив не входят.

## CrossOver

Для проверки создана отдельная бутылка Windows 10 x64 `ByteStoreTest`. В CrossOver запускайте `Run ByteStore.cmd` из распакованной папки: он обеспечивает корректные файловые потоки Windows; прямой запуск EXE через командный канал Wine может давать `EBADF` до загрузки интерфейса. Никакие защитные параметры Chromium для этого не отключаются.

Для автоматической проверки: `ByteStore Admin.exe --smoke-test`. При `BYTESTORE_SMOKE_CREDENTIALS` проверка также выполняет вход администратора, отрисовку 10 разделов, сохранение сессии при перезагрузке и выход. Файл учётных данных храните вне репозитория: `{"users":[{"email":"…","password":"…","admin":true}]}`. Результат пишется в `BYTESTORE_SMOKE_RESULT` или временную папку Windows. Проверка не меняет товары и заказы.
